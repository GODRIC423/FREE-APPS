# FREE APPS

A curated public export of local-first static app prototypes.

## Security posture

- Only static app files are included: `index.html`, `styles.css`, `app.js`, and generated public READMEs.
- Runtime token files, LAN phone-preview bridges, build scripts, caches, databases, `.env` files, local launchers, and local machine paths are excluded.
- These apps do not include backend code, shell access, GitHub credentials, private-repo access, CRM/webhook writes, payment/account integrations, live loadboard scraping, carrier contact, load posting, or external CDNs.
