    How to use Intake Form Builder
    
        
      
    
      
      
        
    1. Set the context. Name the form, the team behind it, and write the intake goal — one sentence about what the form must learn to route the job.
      2. 
        
    2. Add fields. Click + Add field: an editor opens in place. Pick a type (text, choice, phone, file…), a section, and whether it is required. For choice fields, list options separated by |.
      3. 
        
    3. Edit in place. Click Edit on any card to change it right there. Duplicate a card to reuse its shape.
      4. 
        
    4. Reorder. Drag a card by its handle, or use the ↑/↓ buttons. Order carries into the preview and every export.
      5. 
        
    5. Watch the live preview. Fields are grouped by section exactly as a requester would see them, with realistic mock inputs.
      6. 
        
    6. Read the privacy audit. Blockers (sensitive asks like SSNs, card numbers, health data), warnings (missing consent, required overload), and notes recompute live. The health score explains every point gained or lost.
      7. 
        
    7. Fix, then export. Resolve flags by editing fields, then copy the Markdown spec or download JSON/CSV. Deleting a field shows an Undo toast for 7 seconds.
      8.
