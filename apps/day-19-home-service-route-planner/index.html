How to use the Route Planner

  1. Set the day. Pick the route date, day start, depot, per-tech hour cap, and the default drive and admin buffers. Every schedule is computed from these.
  2. Add technicians. Each tech gets their own route, start time, and capacity meter. Use "+ Add tech" for a second van.
  3. Add stop cards. Customer, area, work summary, priority, appointment window, on-site minutes, and an optional per-stop drive override.
  4. Order the route. Use the ↑/↓ arrows on each card for manual ordering, or "Sort by window" to sort every tech's route by window then priority.
  5. Watch the warnings. The planner computes arrival and departure times, flags stops that arrive after their window closes, emergencies buried mid-route, and techs over the day cap.
  6. Read the capacity meters. Each tech shows planned field time against the day cap — green is comfortable, amber is tight, red is over.
  7. Hand it off. The dispatch sheet renders one section per tech. Copy it as Markdown, print it (one page per tech), or download CSV/JSON.
