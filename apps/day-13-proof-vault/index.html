        How to use Proof Vault

        1. Capture a win. Click + New proof card and give it a title, source workflow, and artifact type. One card = one piece of evidence.
        2. Add context and result. Write what the situation was, what measurably changed, and a headline metric. This is the raw material for every future case study.
        3. Tag it. Add comma-separated tags (service, offer, audience) so you can find the right proof fast with search and tag chips.
        4. Run the redaction checklist. Check all five items — names, secrets, financials, visuals, third-party data — before the card can enter approval.
        5. Advance the workflow. Move the card Captured → Redaction review → Pending approval → Approved. Approval requires an approver name; the gate messages tell you what is missing.
        6. Generate a case-study angle. Pick an angle type (metric-led, problem→solution, before/after, trust) and shuffle wording until the draft headline and outline fit.
        7. Export the pack. Copy the Markdown evidence pack, download JSON/CSV, or print a clean report. Everything is a draft for human review.
        8. Load demo / Reset any time to explore with realistic sample cards or start clean. Data never leaves this browser.
