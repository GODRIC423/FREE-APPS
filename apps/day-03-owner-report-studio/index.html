            How to use Owner Report Studio

            1. Set the frame. Enter the business name, report date, period (daily or weekly), and who the report is for.
            2. Add metric rows. For each headline number enter the current value and the prior-period value, pick a format ($, #, %, hrs) and whether up or down is good. Deltas and percent change compute live.
            3. Write the executive summary. Two or three sentences the owner can read in ten seconds: what moved, what's at risk, what needs a decision.
            4. Log wins and risks. Wins are concrete proof points; risks get a severity so the hot ones stand out.
            5. Queue decisions and actions. Every decision gets an owner and a due date; every next action gets an owner and can be ticked done.
            6. Watch Report health. The checklist on the right tells you exactly what's missing — fix items until the badge reads "Ready to send".
            7. Export. Copy the Markdown (Ctrl/Cmd+S), print the clean report page, download a JSON backup, or grab the metrics as CSV. Everything is a draft for human review.
