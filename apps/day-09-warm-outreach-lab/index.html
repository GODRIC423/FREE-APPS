        The Desk Manual
        
        
        How correspondence moves across this desk
        
      
        
      
    
        
    
          
      
        1. Start a letter. Press + New letter (or N). Every prospect gets an envelope in the tray with its own dossier, letter, and string of postmarks.
          2. 
      
        2. Gather the dossier first. Field notes on what you found; one specific, checkable noticed issue; one honest proof point; one gentle ask. Note the claims you must never make — they travel with every export.
          3. 
      
        3. Set the words down. Write on the letter sheet and press brass plates like {{noticed}} to set fill-in slots — the fair copy fills them from the dossier as you type.
          4. 
      
        4. Mind the editor’s pencil. It grades the resolved letter 0–100 and marks every deduction: canned openers, hype words, a letter that never names the business, a missing ask, me-heavy writing. A grade of 70 or better counts as send-ready.
          5. 
      
        5. String the postmarks. Choose a cadence — gentle three letters, standard four, or the slow burn — set the first posting date, and set the postmarks. Stamp each as a human completes it; due and past-due postmarks are counted in the ledger. The string goes quiet on a reply, a meeting, or a pass.
          6. 
      
        6. Move the letter along. Gathering notes → At the desk → Sealed & ready → Posted → Reply received. The ledger above the desk keeps the running count.
          7. 
      
        7. Dispatch to a human. Copy the Markdown packet (Ctrl/Cmd+S), print it, or download JSON and the tray ledger CSV. This desk posts nothing — a person reads, verifies, and sends.
