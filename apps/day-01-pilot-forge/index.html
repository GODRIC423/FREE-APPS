      How to use Pilot Forge

      Pilot Forge turns a rough service-business idea into a scoped AI pilot you can actually pitch: a fit score with reasons, a revenue case, a day-by-day proof plan, and an exportable brief.

      1. Load the demo (button in the metrics strip) to see a finished pilot, or start clean.
      2. Shape the pilot — pick the business type, the wedge (the one leak this pilot fixes), and write the owner's pain in one concrete sentence with a number in it.
      3. Define the proof the owner will see (a report, log, or tracker) and set the automation level. Draft-only scores best — it is the safest thing to sell first.
      4. Read the fit score. Every factor shows its points and a tip when it is weak. Fix the lowest factor until the score is 60+.
      5. Run the numbers — missed leads, close rate, job value, recovery rate. The leak, recoverable revenue, suggested fee, and payback update live.
      6. Edit the proof plan. Milestones are generated from your wedge and proof window. Change days and wording, check them off, add your own, or regenerate.
      7. Work the action board — add tasks, then drag them (or use the arrow buttons) across To do / In progress / Done. Deleting shows an Undo toast.
      8. Export — copy the Markdown brief, download a JSON backup, import it later, or print a clean one-pager. Everything stays a draft for human review.
