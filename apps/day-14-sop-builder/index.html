          How to use SOP Builder

          1. Create an SOP. Click + New in the library (left), or Load demo to explore three finished procedures first.
          2. Fill the overview. Title, owner (a role, not a person), the trigger that starts it, frequency, purpose, inputs, and a definition of done.
          3. Break the work into steps. Each step gets a title, the exact action, an owner, the tool used, and a duration in minutes. Drag the ⣿ handle or use ↑ ↓ to reorder.
          4. Write quality checks. The short inspection list a runner ticks before calling the run done. Tick a box here once you have verified it in a dry run.
          5. Map exception paths. For each way the happy path breaks: what happened, what to do instead, and who to escalate to.
          6. Watch the completeness score. The stat strip and the Fix next list tell you exactly what is still missing.
          7. Export the document. Copy Markdown, print the clean SOP page, or download JSON (whole library, re-importable) and CSV (step table). Everything is a draft for human review.
