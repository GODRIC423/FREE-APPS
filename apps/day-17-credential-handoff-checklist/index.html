How to use this app

  1. Load the demo (header button) to see a realistic small-team inventory, or start clean with + New.
  2. Add each system someone can log into: name, access type and level, primary and backup owner, MFA status, and where the credential lives — the password-manager item label only, never the value. A hard lint blocks anything password-shaped.
  3. Set a rotation date and tick the custody controls you have actually verified. Unchecked controls become risk flags.
  4. Watch the risk register — it lists every gap (no MFA, no backup owner, stale rotation, undocumented revocation) ranked by severity, and rolls them into a 0–100 custody health score.
  5. Move systems across the board: Intake → Verify → Handoff ready → Revoke / remove, as custody is confirmed.
  6. Generate an offboarding runbook: pick the person leaving, get an ordered revoke/rotate/reassign/verify checklist for every system they touch, highest privilege first. Tick steps as you complete them.
  7. Export the custody report as Markdown, JSON, CSV, or print — all metadata-only drafts that require human review and approval before real use.
